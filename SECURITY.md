# Security and privacy

This is a personal local research tool. Keep the web listener on localhost. Source APIs receive search queries; no LLM provider receives application data automatically.

Do not commit `data/`, research requests/results, source PDFs, API keys, `.env` files, SQLite databases, or `.streamlit/secrets.toml`. Portable research ZIPs are user data, not application source. The public repository includes only generic examples and clearly labeled synthetic fixtures.

Use a private GitHub security advisory for credential or data-exposure reports. Do not place credentials or private research content in public issues.
